AMIN ROMS - GitHub Pages

1) Upload index.html to the root of your GitHub repository named amin-roms.
2) Open Settings > Pages.
3) Under Build and deployment choose Deploy from a branch.
4) Choose branch main and folder /(root), then Save.
5) Wait for deployment; your site URL appears in Settings > Pages.

This is a static demo. Admin uploads are stored only in the visitor's browser; a secure server and database are required for shared uploads and real admin authentication.
